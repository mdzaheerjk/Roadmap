## 📐 Phase 2: Statistics & Probability

> **Goal:** Develop the mathematical intuition to understand *why* ML algorithms work, not just *how* to call them.

<details>
<summary><b>🔹 Descriptive Statistics</b></summary>
<br/>

- **Central tendency:** Mean, median, mode — when each misleads you
- **Spread:** Variance, standard deviation, IQR
- **Shape:** Skewness (tail direction), kurtosis (tail heaviness)
- **Visualization:** Box plots, histograms, Q-Q plots

</details>

<details>
<summary><b>🔹 Probability Theory</b></summary>
<br/>

| Concept | Application in ML |
|---------|------------------|
| Random variables | Model outputs as probability distributions |
| Bernoulli / Binomial | Binary classification |
| Poisson | Event count modeling |
| Normal distribution | Assumptions in Linear Regression |
| Central Limit Theorem | Why batch gradient descent works |

</details>

<details>
<summary><b>🔹 Inferential Statistics</b></summary>
<br/>

- **Confidence intervals:** What your model's metric range actually means
- **Hypothesis testing:** A/B testing ML models, p-values, t-tests
- **Chi-square tests:** Categorical feature independence
- **ANOVA:** Comparing means across multiple groups

</details>

<details>
<summary><b>🔹 Bayesian Statistics</b></summary>
<br/>

- Bayes theorem: `P(hypothesis | data) ∝ P(data | hypothesis) × P(hypothesis)`
- Prior, likelihood, posterior — the Bayesian update loop
- Naive Bayes classifiers derived from first principles
- Foundation for probabilistic deep learning & uncertainty quantification

</details>

**Skills acquired:** `Statistics` `Probability` `Hypothesis Testing` `Bayesian Inference` `scipy.stats`

## 🤖 Phase 3: Machine Learning

> **Goal:** Build, evaluate, and tune predictive models across the full classical ML spectrum.

<details>
<summary><b>🔹 Exploratory Data Analysis (EDA)</b></summary>
<br/>

A thorough EDA is what separates good ML engineers from great ones.

| EDA Step | Tools & Techniques |
|----------|--------------------|
| Structure | `.shape`, `.dtypes`, `.describe()`, `.info()` |
| Missing values | Heatmaps (`missingno`), percentage analysis |
| Outliers | Z-score, IQR method, isolation forest |
| Univariate | Histograms, KDE plots, boxplots |
| Bivariate | Scatter plots, correlation coefficients |
| Multivariate | Pair plots, 3D scatter, PCA biplots |
| Correlation | Pearson, Spearman, Kendall heatmaps |
| Imbalance | Class distribution charts, SMOTE strategies |
| Leakage | Time-aware train/test splits, feature audit |

</details>

<details>
<summary><b>🔹 Feature Engineering</b></summary>
<br/>

> "In competitions and production, features beat algorithms."

| Technique | When to Use |
|-----------|------------|
| Imputation (mean/median/KNN) | Missing numerical values |
| One-Hot / Label / Target Encoding | Categorical variables |
| StandardScaler / MinMaxScaler | Distance-based models (KNN, SVM) |
| Log transform | Right-skewed distributions |
| Polynomial features | Capturing non-linear relationships |
| Binning | Converting continuous to ordinal |
| PCA | Reducing dimensionality, removing collinearity |
| RFE / SelectKBest | Feature selection |

</details>

<details>
<summary><b>🔹 Supervised Learning Algorithms</b></summary>
<br/>

| Algorithm | Key Hyperparameters | Best For |
|-----------|--------------------|----|
| Linear Regression | `fit_intercept`, `regularization` | Continuous targets, interpretability |
| Logistic Regression | `C`, `solver`, `penalty` | Binary classification baselines |
| KNN | `n_neighbors`, `metric` | Small datasets, recommendation |
| Naive Bayes | `var_smoothing` | Text classification |
| SVM | `C`, `kernel`, `gamma` | High-dimensional, small datasets |
| Decision Tree | `max_depth`, `min_samples_split` | Interpretable models |

</details>

<details>
<summary><b>🔹 Ensemble Methods</b></summary>
<br/>

| Method | Type | Strength |
|--------|------|----------|
| Random Forest | Bagging | Low variance, robust |
| Gradient Boosting | Boosting | High accuracy |
| XGBoost | Boosting + regularization | Tabular data king |
| LightGBM | Histogram-based boosting | Speed at scale |
| CatBoost | Native categorical handling | Minimal preprocessing |

</details>

<details>
<summary><b>🔹 Unsupervised Learning</b></summary>
<br/>

- **K-Means:** Elbow method, silhouette score, applications in customer segmentation
- **Hierarchical:** Dendrograms, Ward linkage, when clusters have no known count
- **DBSCAN:** Density-based, handles noise, no cluster count needed
- **t-SNE / UMAP:** Dimensionality reduction for visualization
- **Anomaly Detection:** Isolation Forest, One-Class SVM, LOF

</details>

<details>
<summary><b>🔹 Model Evaluation Framework</b></summary>
<br/>

```
Classification Metrics          Regression Metrics
─────────────────────          ──────────────────
Accuracy                       MAE  (Mean Absolute Error)
Precision                      MSE  (Mean Squared Error)
Recall                         RMSE (Root MSE)
F1-Score                       R²   (Coefficient of Determination)
ROC-AUC                        MAPE (Mean Absolute % Error)
Confusion Matrix
Log Loss
```

**Validation strategies:** Hold-out split → K-Fold CV → Stratified K-Fold → Time-series CV

</details>

**Skills acquired:** `scikit-learn` `XGBoost` `LightGBM` `Feature Engineering` `Model Selection` `Cross-validation`

## 📝 Phase 6: Natural Language Processing (NLP)

> **Goal:** Build language intelligence systems from preprocessing through the full Transformer stack.

<details>
<summary><b>🔹 NLP Foundations</b></summary>
<br/>

```
Raw Text → Cleaning → Tokenization → Normalization → Features → Model
```

| Step | Techniques |
|------|-----------|
| Cleaning | Lowercase, remove HTML, punctuation, special chars |
| Tokenization | Word, sentence, subword (BPE, WordPiece) |
| Stemming | Porter, Snowball — aggressive, may lose meaning |
| Lemmatization | spaCy, NLTK — returns base dictionary form |
| Stopword removal | Context-dependent — sometimes keep for meaning |

</details>

<details>
<summary><b>🔹 Text Feature Engineering</b></summary>
<br/>

| Method | Output | Limitation |
|--------|--------|------------|
| Bag of Words | Sparse count vector | No order, no semantics |
| TF-IDF | Weighted sparse vector | Still no semantics |
| N-grams | Phrase-aware sparse vector | Combinatorial explosion |
| Word2Vec | Dense 300-d vector | Context-independent |
| GloVe | Dense vector (global co-occurrence) | Static embedding |
| FastText | Subword-aware dense vector | Handles OOV words |

</details>

<details>
<summary><b>🔹 Sequence Models</b></summary>
<br/>

- **RNN:** Processes sequences step-by-step; suffers from vanishing gradients
- **LSTM:** Gates (input/forget/output) solve vanishing gradient; long-range memory
- **GRU:** Simplified LSTM; fewer parameters, comparable performance
- **Bidirectional variants:** Read sequence forwards AND backwards for richer context

</details>

<details>
<summary><b>🔹 Attention & Transformers</b></summary>
<br/>

```
Input → Tokenize → Embed → [Multi-Head Attention → FFN] × N → Output
                                      ↑
                            Query × Key → Score → Value
```

| Model | Architecture | Training | Best For |
|-------|-------------|---------|----------|
| BERT | Encoder-only | MLM + NSP | Classification, NER, QA |
| GPT | Decoder-only | Causal LM | Generation, completion |
| T5 | Encoder-decoder | Seq2Seq | Translation, summarization |
| RoBERTa | BERT improved | More data, no NSP | BERT tasks, stronger |

</details>

<details>
<summary><b>🔹 Advanced NLP Tasks</b></summary>
<br/>

| Task | Models | Datasets to Know |
|------|--------|-----------------|
| Text classification | BERT fine-tune, DistilBERT | SST-2, AG News |
| Named Entity Recognition | spaCy, BERT-NER | CoNLL-2003 |
| Sentiment analysis | VADER, RoBERTa | IMDB, Yelp |
| Question answering | BERT, RoBERTa | SQuAD 2.0 |
| Machine translation | MarianMT, NLLB | WMT datasets |
| Summarization | BART, T5, Pegasus | CNN/DailyMail |

</details>

**Skills acquired:** `NLTK` `spaCy` `HuggingFace Transformers` `BERT` `GPT` `Text Classification` `NER`

## 📦 Phase 8: Retrieval-Augmented Generation (RAG)

> **Goal:** Ground LLMs in real, up-to-date, private knowledge — eliminate hallucination at scale.

<details>
<summary><b>🔹 Vector Databases & Embeddings</b></summary>
<br/>

```
Document → Embed (model) → Vector → Store in VectorDB → Query by similarity
```

| Database | Best For | Notes |
|----------|----------|-------|
| **FAISS** | Local, research, speed | In-memory, no server |
| **Chroma** | Local dev, prototyping | Easy Python API |
| **Pinecone** | Managed cloud production | Fully hosted |
| **Weaviate** | Hybrid search production | Open-source + cloud |
| **pgvector** | PostgreSQL + vectors | Best for existing PG setups |
| **Qdrant** | High-performance production | Rust-based, fast |

**Similarity metrics:** Cosine similarity, Dot product, Euclidean distance

</details>

<details>
<summary><b>🔹 RAG Architecture</b></summary>
<br/>

```
         ┌─────────────────────────────────────┐
         │           RAG Pipeline              │
         └─────────────────────────────────────┘
                          │
         ┌────────────────┼────────────────┐
         ▼                ▼                ▼
   [INGESTION]      [RETRIEVAL]       [GENERATION]
   Load docs        Embed query       Retrieved chunks
   Chunk text       Search VectorDB   + Query → LLM
   Embed chunks     Top-K results     → Final answer
   Store vectors    Re-rank
```

**Chunking strategies:**

| Strategy | Best For |
|----------|----------|
| Fixed-size (512 tokens) | Uniform documents |
| Sentence-based | Conversational, QA data |
| Recursive character | General purpose (LangChain default) |
| Semantic chunking | Highly structured documents |
| Parent-child | Multi-level retrieval |

</details>

<details>
<summary><b>🔹 Advanced RAG Techniques</b></summary>
<br/>

| Technique | What It Solves |
|-----------|---------------|
| Hybrid search | Combines dense (semantic) + sparse (BM25) retrieval |
| Re-ranking | Cross-encoder scores top-K results for precision |
| HyDE | Hypothetical Document Embeddings for better queries |
| Self-query | LLM generates structured metadata filters |
| RAPTOR | Recursive summarization for multi-level retrieval |
| Memory integration | Conversation history aware retrieval |

</details>

<details>
<summary><b>🔹 Multimodal RAG</b></summary>
<br/>

- **Image + Text retrieval:** CLIP embeddings for visual search in documents
- **OCR + LLM pipelines:** Extract text from PDFs, tables, and images
- **ColPali:** Page-level multimodal document retrieval (no OCR needed)
- **Unstructured.io:** Parse PDFs, PPTs, Word docs for ingestion

</details>

**Skills acquired:** `FAISS` `Chroma` `Pinecone` `pgvector` `LangChain` `LlamaIndex` `Embedding Models`

## 🤖 Phase 9: Agentic AI & Autonomous Systems

> **Goal:** Build AI that can reason, plan, use tools, and complete multi-step tasks autonomously.

<details>
<summary><b>🔹 Agentic AI Foundations</b></summary>
<br/>

```
LLM alone:    Query → LLM → Answer
LLM + Agent:  Query → LLM → Plan → Tools → Observe → LLM → Plan → ... → Answer
```

| Concept | Description |
|---------|-------------|
| Agent loop | Perceive → Think → Act → Observe → Repeat |
| Tool use | LLM decides when/how to call functions |
| ReAct pattern | Reasoning + Acting interleaved |
| Planning | Decompose complex goals into sub-tasks |
| Memory types | Working memory, episodic, semantic, procedural |
| Multi-agent | Specialized agents collaborating via message passing |

</details>

<details>
<summary><b>🔹 LangChain</b></summary>
<br/>

| Component | Purpose |
|-----------|---------|
| `ChatPromptTemplate` | Structure system + user messages |
| `LLMChain` | Prompt → LLM → Output Parser |
| `AgentExecutor` | Run agent with tools |
| `Tool` | Wrap any function for agent use |
| `Memory` | `ConversationBufferMemory`, summary memory |
| `Callbacks` | Logging, tracing (LangSmith) |

</details>

<details>
<summary><b>🔹 LangGraph</b></summary>
<br/>

LangGraph treats agent workflows as **stateful graphs** — perfect for complex, branching agentic behavior.

```python
# LangGraph mental model
State → Node (LLM call / tool) → Conditional Edge → Node → ... → END
```

| Feature | Description |
|---------|-------------|
| `StateGraph` | Define nodes and directed edges |
| Conditional edges | Route based on LLM output |
| Checkpointers | Persist state across interruptions |
| Human-in-the-loop | Pause graph, wait for human input, resume |
| Streaming | Stream partial output from any node |
| Multi-agent | Supervisor + worker agent topology |

</details>

## 🚀 Phase 10: Production Deployment & Multi-Agent Systems

> **Goal:** Move from notebook to production — build scalable, monitored, deployable AI systems.

<details>
<summary><b>🔹 Backend & APIs</b></summary>
<br/>

```python
# FastAPI — the standard for ML/AI APIs
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class InferenceRequest(BaseModel):
    text: str
    model: str = "default"

@app.post("/predict")
async def predict(req: InferenceRequest):
    result = model.infer(req.text)
    return {"prediction": result}
```

- **FastAPI:** Async, auto-docs (Swagger), Pydantic validation, dependency injection
- **REST API design:** Versioning (`/v1/`), error handling, rate limiting, auth (JWT/API keys)
- **WebSockets:** For streaming LLM responses token-by-token
- **Background tasks:** Async inference queues with Celery / ARQ

</details>
